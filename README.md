# manim-sideview-pycharm

A simple PyCharm plugin to run Manim scenes and preview the output directly in the IDE.

## Features

- Adds **Run Manim Scene** action available from the toolbar and the `Find Action` menu.
- Saves all documents, runs `manim` on the current file and displays the command output.
- Minimal skeleton built using the [gradle-intellij-plugin](https://github.com/JetBrains/gradle-intellij-plugin).

This project is an early prototype inspired by the [Manim Sideview](https://github.com/Rickaym/Manim-Sideview) extension for VSCode.
